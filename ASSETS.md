# Generated server imagery

Both images were generated with the built-in `image_gen` tool, inspected visually, then resized and encoded as WebP for the website. No image API key or paid API integration was added to this project.

## Homepage

Saved assets: `assets/images/hosting-hero-960.webp`, `assets/images/hosting-hero-1600.webp`, `assets/images/hosting-hero-1920.webp` and `assets/images/hosting-hero-mobile.webp`. The mobile variant crops to the hardware on the right. The build copies these into `dist/assets/images/`.

Final prompt:

> Use case: ads-marketing. Asset type: high-resolution 16:9 homepage hero background for Server Anywhere, a premium Bangladesh cloud hosting website. Create a striking, realistic luxury technology product photograph/render. Preserve usable clean negative space on the LEFT 48 percent for dark purple text; that left half is a very pale lavender-white seamlessly blending into the scene. On the RIGHT 52 percent, a beautifully detailed group of three real dark gunmetal server rack cabinets, one tall and two slightly lower, in a tasteful three-quarter perspective on a polished pale lavender platform, fine brushed aluminum, realistic rackmounted servers with tiny teal status LEDs, perforated grille panels and authentic ports, sophisticated luminous violet edge lighting, softly lit glass cloud in background only as small subtle accent. Eye-catching dimensional depth with soft realistic grounded shadows and subtle studio haze. Calm, precision enterprise infrastructure, photorealistic material quality, restrained purple and icy blue lights that harmonize with #7151d9 and #f0ecfc. Main server detail should occupy right third and be clearly visible at crop to that right third on mobile. Light airy studio rather than dark gaming room, editorial product photography, crisp hardware detail. No people, no text, no letters, no logos, no watermarks, no cartoon shapes, no clipart, no excessive neon. Landscape composition.
